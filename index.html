Votre entreprise (par nom ou SIREN) ou seulement votre code NAF, et vos rôles. Le profil reste dans ce navigateur : rien n'est envoyé au serveur.

1 · Votre entreprise
ou seulement un code NAF :

Sources : Sénat (amendements, sénateurs — data.senat.fr) ; API Recherche d'entreprises (recherche-entreprises.api.gouv.fr : unités légales actives, code NAF, tranches d'effectifs INSEE, chiffre d'affaires publié) ; Sénat (Ameli, amendements depuis 2001) ; HATVP (répertoire des représentants d'intérêts).

Euros : fourchette basse – haute = chiffre d'affaires publié × taux par secteur, chaque paramètre tiré d'une citation vérifiée (« détails »). Les mesures sont chiffrées séparément ; certaines sont des alternatives, les totaux ne sont donc pas un effet cumulé certain.

Employés concernés : fourchette basse – haute, calculée à partir des tranches d'effectifs INSEE de toute l'entreprise. Critères extraits par IA à partir du texte de l'amendement, citation à l'appui (« détails »).

Soutien : nombre de groupes politiques qui déposent la même mesure. C'est un signal descriptif, pas une prévision du vote.

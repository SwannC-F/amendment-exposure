Un projet de loi a une étude d'impact, pas un amendement. Cherchez votre entreprise : voici les amendements en attente qui la concernent, ce qu'ils déplacent pour elle en euros, combien d'entreprises et d'employés sont exposés, et qui les porte au Sénat.

Exemples :

Sources : Sénat (amendements, sénateurs — data.senat.fr) ; API Recherche d'entreprises (recherche-entreprises.api.gouv.fr : unités légales actives, code NAF, tranches d'effectifs INSEE, chiffre d'affaires publié) ; Sénat (Ameli, amendements depuis 2001) ; HATVP (répertoire des représentants d'intérêts).

Euros : fourchette basse – haute = chiffre d'affaires publié × taux par secteur, chaque taux tiré d'une source citée (« détails »). Les mesures sont chiffrées séparément ; certaines sont des alternatives, les totaux ne sont donc pas un effet cumulé certain.

Employés concernés : fourchette basse – haute, calculée à partir des tranches d'effectifs INSEE de toute l'entreprise. Critères extraits par IA à partir du texte de l'amendement, citation à l'appui (« détails »).

Soutien : nombre de groupes politiques qui déposent la même mesure. Majorité sénatoriale = Les Républicains + Union centriste. C'est un signal descriptif, pas une prévision du vote.
